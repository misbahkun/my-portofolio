Magang pertama sebagai developer adalah pengalaman yang sangat berharga buat saya. Di sini saya ingin berbagi cerita dan pelajaran yang saya dapat selama proses magang.

## Persiapan Sebelum Magang

Sebelum memulai magang, saya mempersiapkan beberapa hal:

1. **Portfolio** — Memastikan project-project di GitHub terorganisir dengan baik
2. **CV** — Menyusun CV yang fokus pada skill teknis
3. **Belajar** — Memperdalam framework yang dipakai perusahaan

## Day 1

Hari pertama selalu bikin deg-degan. Yang saya lakukan waktu itu:

- Kenalan dengan tim
- Setup development environment
- Baca dokumentasi project yang akan dikerjakan, tapi waktu itu saya apes nya memang handle project yang ga ada dokumentasi nya, jadi mau gak mau minta AI buat bantu summary codebase nya dan itu sangat amat membantu sekali untuk memahami codebase kita yang tidak ada sama sekali docs nya.
- Mencoba running di local, dan ternyata lumayan lancar, meskipun ada beberapa hal yang harus di configure terlebih dahulu env nya.

## Pelajaran yang Didapat

### 1. Code Review itu Penting

Sebelum magang, saya jarang melakukan code review. Di perusahaan, setiap pull request harus di-review minimal satu orang. Ini mengajarkan saya untuk menulis kode yang lebih bersih dan mudah dipahami.

### 2. Git Workflow

Karena saya magang di salah satu startup di Tegal, untuk git worklow lumayan lengkap mulai dari membuat branch, staging, production — semua punya aturan sendiri. Jadi jangan asal ya nanti kena pentung PM loh kwkw

### 3. Komunikasi

Skill teknis penting, tapi kemampuan berkomunikasi dengan tim sama pentingnya.

## Tips untuk yang Mau Magang

- Jangan takut apply walaupun merasa belum siap
- Buat portfolio yang menunjukkan kemampuan dan tampilkan 3 project terbaik
- Pelajari tech stack perusahaan yang dituju
- Siapkan pertanyaan saat interview
- Jadilah proaktif selama magang

Magang adalah jembatan antara dunia akademik dan dunia kerja. Manfaatkan sebaik-baiknya!
